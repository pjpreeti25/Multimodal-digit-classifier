# Notebooks Directory

This directory contains Jupyter notebooks for the multimodal digit classification project.

## Files

- `mutlimodal_fusion.ipynb` - Main analysis notebook with complete multimodal digit classification workflow

## Usage

To run the notebooks:

1. Ensure you have the required data files in the `data/` directory
2. Install dependencies: `pip install -r requirements.txt`
3. Start Jupyter: `jupyter notebook`
4. Open `mutlimodal_fusion.ipynb.ipynb`

## Notebook Contents

The main notebook includes:
- Data loading and preprocessing
- Model architecture definition
- Training with hyperparameter tuning
- Evaluation and visualization
- Final predictions generation
