# Predictions Directory

This directory contains the final predictions generated by the multimodal digit classification model.

## Files

- `final_preds.csv` - Final predictions for the Kaggle competition test set

## File Format

The predictions file contains the following columns:
- `row_id`: Sequential identifier for each test sample (0, 1, 2, ...)
- `Digit_Probability`: Predicted digit class (0-9) for each sample

## Example Format

```csv
row_id,Digit_Probability
0,7
1,2
2,1
3,0
4,4
...
```

## Model Performance

- **Kaggle Competition Score**: 0.969 (excellent performance!)
- **Model Architecture**: Multimodal fusion of image and audio encoders
- **Best Hyperparameters**: Learning rate = 0.001, Batch size = 32, Optimizer = SGD
- **Training Approach**: Grid search optimization with validation

## Generation Process

The predictions were generated using the following workflow:

1. **Data Preprocessing**: Load and reshape test data
2. **Model Loading**: Load the trained multimodal model
3. **Prediction**: Generate predictions on test set
4. **Formatting**: Convert to submission format
5. **Saving**: Export as CSV file

## Usage

To regenerate predictions:

```python
from src.preprocess import preprocess_data
from src.train import train_multimodal_model
from src.evaluate import generate_predictions

# Load and preprocess data
data = preprocess_data()

# Train model (or load pre-trained)
best_model, best_params, history = train_multimodal_model(data)

# Generate predictions
predictions = generate_predictions(
    best_model, 
    data['image_test'], 
    data['audio_test'],
    save_path='preds/'
)
```
